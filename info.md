# TESMart LAN Matrix

GUI-configurable Home Assistant integration for TESMart LAN matrix switches.

Features:

- Config flow (no YAML required)
- Options flow for model and polling
- Only supported models: 8x16 and 16x16
- One selector per output for fast routing
- Global selector to set all outputs to one input
- Preset slot selector (1-8)
- Mirror / Load preset / Save preset buttons
- Buzzer and auto-input switches
- LED timeout selector
- Fan mode selector (experimental mapping)
